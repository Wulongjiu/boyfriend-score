### ⚠️ 命名带来的文案约束（重要）
「生存指数」是**玩梗**，不是威胁。它带来 3 条必须遵守的约束：

1. **首页首屏**必须立刻表明是玩梗（tagline 已写"看看他能不能活下来"），否则第一眼像"评判男友该不该死"。
2. **低分档禁止**写成"这男的不能要 / 建议换一个"——用户看到的是自己的关系，要接住她，不是判决他。
3. **等级称号**要与"生存"框架呼应但不血腥：现有 6 档（人间理想·限量款 / 别人家的男朋友 / 及格线以上的甜 / 还行，但可以更好 / 需要认真聊一次 / 姐妹，你值得更好的）**不含**"淘汰/阵亡/凉了"这类词，是刻意为之，后续加档位请保持。

命名原则：不叫"心理测评/情感测试"（合规与审核风险 + 用户预期过高），一律叫"测一测/打个分"。

## 3. 目标用户与使用场景

| 维度 | 描述 |
|---|---|
| 核心人群 | 18–30 岁女性，恋爱中或长期暧昧，小红书活跃 |
| 情绪动机 | 想**验证**心里已有的判断；想找"证据"；想有理由吐槽或炫耀 |
| 触发场景 | 吵架后 / 纪念日前 / 闺蜜讨论时 / 刷到别人晒分数 |
| 分享动机 | 分数高 → 炫耀；分数低 → 求安慰与共鸣（两种都会分享，这是关键） |
| 反面人群 | 明确不想被评价关系的人 → 不强求，页面文案不做挑衅 |

**核心洞察**：用户不是来"求答案"的，是来**求认同**的。因此结果文案必须站在她这边，不替男友辩解、不指责她。

## 4. 核心指标（上线前锁定，否则无法判断成败）

| 指标 | 定义 | 目标 | 埋点事件 |
|---|---|---|---|
| 完成率 | 完成测评 / 点击开始 | ≥ 55% | `start_quiz` → `quiz_complete` |
| 分享率 | 生成卡片 / 完成测评 | ≥ 25% | `quiz_complete` → `save_image` |
| K 因子 | 每用户带来的新用户 | ≥ 0.3（破 1 才能自传播） | 带参链接访问 → `start_quiz` |
| 首屏跳出 | 进首页未点开始 | < 45% | `view_home` → `start_quiz` |
| 犹豫题 | 单题停留 > 15s 的分布 | 观察项 | `answer_q{n}` + `duration` |

**北极星指标**：**分享率**。完成率高但没人分享 = 产品没有生命力。

## 5. 明确"不做"清单（v1 边界）

- ❌ 不做注册/登录/手机号（摩擦 + 合规风险）
- ❌ 不收集真实姓名、照片、聊天记录、对方身份信息
- ❌ 不做心理/医学诊断表述，不做"是否该分手"的直接结论
- ❌ 不做付费与会员（第一版）
- ❌ 不做 App / 小程序（先验证网页）
- ❌ 不做双人对照、历史记录、闺蜜版（v2 候选）
- ❌ 不在小红书笔记里放二维码、不写站外导流话术

## 6. 测评模型（已实现于 `lib/scoring.ts`，可配置）

### 6.1 结构
- **总分**：0–100，由七个维度加权求和
- **维度得分**：每维独立归一化到 0–100，避免"题多的维度权重被放大"
- **维度权重**（合计 100）：

| 维度 | 权重 | 理由 |
|---|---|---|
| D1 情绪价值与沟通 | 20% | 分手第一因，权重最高 |
| D2 时间与陪伴质量 | 15% | 可感知、可举证 |
| D3 边界感与异性社交 | 15% | 最容易出红牌、最容易吵 |
| D4 未来规划与承诺 | 15% | 关系确定性来源 |
| D5 责任分担与成长 | 15% | 长期关系的地基 |
| D6 仪式感与礼物 | 10% | 高感知但不该主导评分 |
| D7 家人朋友与社交融合 | 10% | 相对慢变量 |

> 权重写在 `lib/model.ts` 的 `DIMENSIONS` 中，改权重不需要改任何计分代码。

### 6.2 评分规则
- 每题 4 个选项，分值 0–4（分值越高＝这项做得越好）
- 维度得分 = 该维已答题实得分 / 该维已答题满分 × 100（保留 1 位小数）
- 总分 = Σ(维度得分 × 权重) / 100，四舍五入取整
- 未作答的题在该维度内**不参与分母**（不计为 0 分，避免误伤）

### 6.3 等级（6 档）

| 分数 | 称号 | 一句话 |
|---|---|---|
| 95–100 | 人间理想·限量款 | 这种人建议你藏好，别发朋友圈 |
| 85–94 | 别人家的男朋友 | 姐妹，你已经被羡慕了一大片 |
| 70–84 | 及格线以上的甜 | 有爱的底子，有几个地方值得聊聊 |
| 55–69 | 还行，但可以更好 | 他不是不爱你，是没学会怎么爱 |
| 40–54 | 需要认真聊一次 | 有些事再拖，就变成你的委屈了 |
| 0–39 | 姐妹，你值得更好的 | 这个分数不是你的错，真的 |

### 6.4 红牌机制（一票预警）
命中任一红牌题 → 结果页单独展示警示区，且**总分封顶 45 分**（进入「需要认真聊一次」档）。

> 设计意图：防止"他天天冷暴力但礼物送得好，最后得 82 分"这种伤害用户的结论。
> 红牌不是判定"他是坏人"，而是提示"这里有件事值得你认真看"。

v1 红牌题：
- D1·Q3 冷暴力 / 阴阳怪气
- D1·Q5 你难过时他说"是你想多了 / 你又来了"
- D3·Q2 和异性暧昧不承认、说你多想
- D5·Q4 在别人面前贬低你、开你玩笑
- D5·Q5 迁怒、摔东西、让你害怕

### 6.5 一致性校验（防瞎答）
3 组反向验证题对，正反向差异均值超过阈值 → 提示"你的答案有点矛盾哦，结果仅供参考"。
- 参与度低时**不改变分数**，只做提示（避免误伤真实用户）

### 决策 4 的落地约束（Day 12 实现分享时按这个来）

- **默认路径：PNG 卡片**。用户保存后自己发小红书，站点不参与传播，隐私风险最低。
- **分享链接只允许出现：分数 + 等级称号 + 站点名**。
  - ❌ 不得展示七维得分、雷达图明细、红牌内容、任何题目答案
  - 有效期 7 天，过期跳回首页
  - 链接页 `robots: noindex`，不进搜索引擎
- **导流不靠链接**：小红书笔记内不放二维码、不写外链，用站内关键词「男友生存指数」承接。
- 埋点必须能区分「保存卡片」与「打开链接」两条路径，否则算不出真实 K 因子。
